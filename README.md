# Phishing Awareness Training

## Horizon TechX — Cyber Security Internship | Task 2

### Project Overview
This project focuses on phishing awareness and cybersecurity education. It explains how phishing attacks work, how to recognize suspicious emails and messages, and how individuals can protect themselves from online scams.

### Objectives
- Understand phishing and its common types.
- Identify suspicious emails, SMS messages, and links.
- Recognize social engineering techniques.
- Learn safe browsing and account protection practices.
- Understand how to report suspected phishing attempts.

### Topics Covered
- Introduction to phishing
- Email and SMS phishing (smishing)
- Common phishing warning signs
- Suspicious URLs and malicious links
- Social engineering tactics
- Prevention and security best practices
- Reporting phishing attempts
- Awareness quiz and safety checklist

### Key Safety Practices
1. Verify the sender before trusting a message.
2. Avoid clicking unexpected links or attachments.
3. Check website URLs carefully.
4. Never share passwords or OTPs.
5. Enable multi-factor authentication (MFA).
6. Report suspicious messages through official channels.

### Project Deliverable
**Presentation:** `HorizonTechX_Phishing_Awareness_Final.pptx`

The presentation provides practical examples, prevention techniques, and a checklist to help users recognize and avoid phishing attempts.

### Tools Used
- Microsoft PowerPoint
- GitHub
- Cybersecurity awareness and research

### Learning Outcomes
This project improves awareness of phishing threats, social engineering, suspicious links, and practical measures for safer online behavior.
